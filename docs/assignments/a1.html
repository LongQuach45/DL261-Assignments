Methodology

The current source defines three implemented model families: a linear classifier over flattened pixels, an MLP over flattened pixels, and a CNN for one-channel Fashion-MNIST images.

  • Linear classifier: flatten image, then one linear layer to class logits.
  • MLP: flatten image, two hidden linear stages with BatchNorm/ReLU/Dropout, then class logits.
  • CNN: two Conv2d + BatchNorm + ReLU + MaxPool blocks, followed by a linear classifier head.
  • Loss in source: CrossEntropyLoss; no softmax is applied before the loss.
  • Optimizer in source: Adam.
