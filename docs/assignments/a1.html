Problem Statement

The current source implements an image-classification pipeline for Fashion-MNIST. Inputs are 28x28 grayscale images, and outputs are logits over the 10 Fashion-MNIST classes.

Fashion-MNIST image classification with five mandatory architectures: Linear, MLP, CNN, LSTM, and Transformer. The source and reproduction commands are documented in the Assignment 1 README.

Dataset Description and EDA

The current code uses torchvision.datasets.FashionMNIST as the default dataset, downloaded at runtime into a local data/ directory. It also includes a CIFAR-10 branch in the data loader, but the current main script uses the default Fashion-MNIST path.

  • Current split in source: 50,000 training samples, 10,000 validation samples, and the official 10,000-sample test set.
  • Split seed in source: 42, using torch.Generator().manual_seed(seed).
  • Preprocessing in source: ToTensor() and normalization with mean/std (0.5,) for Fashion-MNIST.
  • EDA helper present: prints total training samples, image shape, class counts, and representative class samples.

EDA outputs, deterministic splits, preprocessing artifacts, and dataset policy are documented in the source README and stored under source/results.

Methodology

The current source defines three implemented model families: a linear classifier over flattened pixels, an MLP over flattened pixels, and a CNN for one-channel Fashion-MNIST images.

  • Linear classifier: flatten image, then one linear layer to class logits.
  • MLP: flatten image, two hidden linear stages with BatchNorm/ReLU/Dropout, then class logits.
  • CNN: two Conv2d + BatchNorm + ReLU + MaxPool blocks, followed by a linear classifier head.
  • Loss in source: CrossEntropyLoss; no softmax is applied before the loss.
  • Optimizer in source: Adam.

The completed source compares Linear, MLP, CNN, row-sequence LSTM/GRU, and patch-based Transformer models, with matched-budget and CIFAR-10 extensions.
