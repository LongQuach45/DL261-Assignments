Foundations of Deep Learning Pipelines and Architectures

From linear models to modern sequence models: a comparative study for image classification.

InstructorLê Thành Sách
DatasetFashion-MNIST
GroupMobyDick
Seed42

Problem statement

We study image classification on Fashion-MNIST using five mandatory architecture families: Linear, MLP, CNN, LSTM/GRU, and Transformer. The same data policy and evaluation metrics are used for the main comparison.

Dataset description and EDA

Fashion-MNIST contains 28×28 grayscale images across 10 classes. The source uses 50,000 training images, 10,000 validation images, and the official 10,000-image test set, with seed 42 and normalization by mean and standard deviation 0.5.

EDA outputs and preprocessing examples are available in the Fashion-MNIST results directory.

Methodology

The main comparison implements a linear classifier, MLP, CNN, row-sequence LSTM/GRU, and patch-based Transformer. All models use cross-entropy loss and are trained with Adam under a matched reproducibility policy.

Experimental setup

Runs use seed 42, batch size 64, 10 epochs, and CUDA when available. The best checkpoint is selected by validation Macro-F1 before final test evaluation. Detailed commands and dependencies are documented in the source README.

Results

Comparison summaries, learning curves, confusion matrices, representative predictions, robustness plots, and interpretability outputs are available in source/results. The narrative final report will be published when provided.

Comparison and discussion

The result artifacts support comparison by accuracy, Macro-F1, parameter count, training behavior, inference cost, robustness, and matched parameter budget. The final written discussion is pending the report deliverable.

Error analysis

Confusion matrices, representative examples, robustness curves, and saliency visualizations provide evidence for class confusion, noise sensitivity, and representation differences. Detailed error interpretation will be included in the final report.

Limitations and conclusion

Current limitations include the short training budget and the pending final report analysis. The repository contains the implementation and generated artifacts required to reproduce the current study.
