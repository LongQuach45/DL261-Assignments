Problem statement

Given one RGB food image, predict one label from a fixed ten-class Food-101 subset. The study focuses on fine-grained visual classification and compares a self-implemented baseline with transfer learning.

Dataset description and EDA

Food-101 provides food images with category labels. The selected classes are balanced at 750 training and 250 test images per class. EDA includes class counts, dimensions, aspect ratios, representative samples, image-readability checks, exact hashes, and perceptual duplicate auditing.

Detailed dataset source and usage information are recorded in the Dataset Proposal.

Methodology

The baseline is a custom CNN trained from scratch. The transfer-learning model is ImageNet-pretrained ResNet-50 with a new ten-class head, evaluated with both a frozen backbone and full fine-tuning. Inputs are normalized 224×224 RGB tensors.

Experimental setup

The controlled comparison uses the same classes, split, seed 42, preprocessing, metrics, and checkpoint rule. The official test set remains untouched. Reproduction commands, environment details, and checkpoint traceability are documented in the source README.

Results

Quantitative summaries, curves, confusion matrices, per-class metrics, qualitative examples, Grad-CAM visualizations, and augmentation-ablation results are available in source/results. The final narrative report is pending.

Comparison and discussion

The controlled study compares the custom CNN, frozen ResNet-50, and full fine-tuning by accuracy, Macro-F1, parameter count, training time, inference latency, and memory. Interpretation will be consolidated in the final report.

Error analysis

Per-class metrics, top-confused pairs, representative correct and failed predictions, and Grad-CAM overlays support analysis of visually similar food categories and model attention. The written error analysis is pending the final report.

Limitations and conclusion

Conclusions apply only to the fixed ten-class subset. Known limitations include noisy web-scale labels, visual similarity between categories, and the compute budget used for fine-tuning.
