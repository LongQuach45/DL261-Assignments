Problem Statement

Food-101 fine-grained food-image classification using a fixed ten-class subset. Task, input, output, motivation, and difficulty are specified in the Dataset Proposal.

Dataset Description and EDA

The approved proposal defines the dataset source, version, usage terms, annotations, 7,500/2,500 sample counts, split plan, leakage controls, and EDA. Implementation artifacts are available in source/results.

Methodology

The completed source includes a custom CNN baseline, ImageNet-pretrained ResNet-50 with frozen and full fine-tuning configurations, cross-entropy loss, accuracy, macro-F1, and the documented preprocessing pipeline.

Experimental Setup

The controlled study, augmentation ablation, seeds, checkpoint rules, hardware records, and compute measurements are documented in the Assignment 2 README.

Results

Quantitative summaries, curves, confusion matrices, per-class metrics, qualitative examples, Grad-CAM outputs, ablation results, training time, inference latency, and memory measurements are available under source/results. The final narrative report will be added later.

Comparison and Discussion

Comparison tables and experiment artifacts are available in the source results directory. Written discussion will be included in the final report.

Error Analysis

Per-class metrics, top-confused pairs, qualitative examples, and Grad-CAM visualizations support the planned error analysis. The written analysis will be added to the final report.

Limitations and Conclusion

Data, method, compute, and generalization limitations will be summarized in the final report.
